# Handoff: i18n (languages, names, static data)

Owner: i18n agent. Files: `src/i18n/**` (except `locales/*/prompt.json`, owned by src/game), `src/data/**`
(except `metadata.ts`, `ds/`), `tests/i18n/**`, `tools/`, `docs/glossary.md`.

## What was built

- **Language layer** (`src/i18n/index.ts`, DS port kept compatible). Detection: `?lang=` (en, zh, zh-CN, zh-TW…,
  en-XA) → `localStorage["ts-playfield.lang"]` (before QA round 3 `tsp.lang`, still read once and copied over) → `navigator.languages` (first entry we have wins; any `zh*` → zh-CN, any
  `en*` → en) → `en`. Switchable at runtime; updates `<html lang>` and `document.title` (`ui:app.documentTitle`).
  zh-CN catalogs are a lazy chunk. Pseudo-language `?lang=en-XA` marks every string `⟦…⟧`.
- **React binding** (`src/i18n/react.ts`): `useI18n()` / `useLanguage()` (useSyncExternalStore). Verified in
  Chromium (Playwright): Chinese browser starts in Chinese, switching re-renders, choice survives reload, `?lang=`
  wins and is dropped from the URL on a switch.
- **Names come from data, not catalogs**: `cardName/cardDescription` = our `card_text.json` titles/texts (they are on
  our Chinese card images; DS titles differ on 50 cards); `countryName/countryShortName/regionName/regionNameById`
  = `src/data/countries.ts`. The DS `game` namespace is gone.
- **Data** (`src/data/`): `cards.ts` and `countries.ts` are GENERATED by `node tools/gen-data.mjs` (cross-checks
  every field against `src/data/ds/*.json`; `--check` for staleness). `effects.ts` = DS `EFFECT_INFO_MAP` as data.
  `index.ts` = lookups and helpers.
- **Glossary** (`docs/glossary.md`) derived from the Chinese card images, applied to every DS zh-CN catalog (148
  values: DEFCON, 调整/调整掷骰, 稳定值, VP, 弃掉, 抽牌堆, 正面朝下, 战争早期/中期/晚期, our card titles). A test bans the old terms.
- **`ui` namespace** (en + zh-CN): app title, menu, side choice, resume, language names, links (rules PDF,
  DeepStruggle, leaderboard, model), about/credits/trademark, loading stages keyed by `LoadProgress.stage`, game
  controls (undo, resign + confirm, new-game confirm), AI thinking, tracks, piles, China Card face up/down, headline,
  card labels (= `card_text.json` labels), regions, settings, endings (one text per `EndingReason`, draw variants),
  errors/reconnect.
- **Namespaces removed** (DS workbench only): page, app, debug, replay, analysis, trace, leaderboard, result, game.
  Kept: common, hud, rolls, region, map, tracks, cards, branches, effects, enums, endings, actions, log, prompt, ui.

## Public API

`src/i18n` (all DS exports kept; `english` args are now optional):
`t`, `message`, `messageIfKnown`, `render`, `renderEnglish`, `Message`, `MessageArg`, `MessageKey`, `MessageFormat`,
`cardName(id, english?)`, `cardDescription(id, english?)` (plain text), `countryName(id, english?)`,
`countryShortName(id)`, `regionName(englishOrKey)` ("Middle East", "MIDDLE_EAST", "Se Asia"), `regionNameById(id)`,
`sideName(side)`, `effectText(flag)`, `language()`, `isChinese()`, `currentDataLang()`, `initLanguage(env?)`,
`setLanguage(lang)`, `onLanguageChange(fn)`, `detectLanguage(env)`, `normalizeLanguage(tag)`, `browserEnvironment()`,
`htmlLang`, `LANGUAGES`, `PSEUDO`, `STORAGE_KEY`; DOM-only `applyStatic`, `bindLanguageSelects` (not needed).
`src/i18n/react`: `useI18n()` → `{lang, t, render, setLang, cardName, cardDescription, countryName,
countryShortName, regionName, regionNameById, sideName}`; `useLanguage()`.
`src/i18n/endings`: `endingMessages(ending, humanSide)` → `{title, text, outcome}` Messages; `cardListArg(ids)`.
`src/i18n/enums`: unchanged DS port.
`src/data`: `CARDS`, `CardInfo` (`id, ops, side "US"|"USSR"|"NEUTRAL", era, starred, scoring, war, optional,
title{en,zh}, text{en,zh}`), `COUNTRIES`/`CountryInfo` (`engineName, name, short, region, subregions, stability,
battleground, superpowerAdjacent "US"|"USSR"|null, neighbours, layout{ds, board}`), `REGIONS`, `SUBREGIONS`,
`EFFECT_INFO_MAP`, `EFFECT_FLAGS`, `effectInfo`, `cardInfo`, `countryInfo`, `countryByEngineName`, `regionInfo`,
`areaByName`, `cardImageUrl(id, lang)` (BASE_URL + `cards/{en|zh}/NNN.webp`), `cardTextLines` (zh `*…*` italics,
`\n`), `cardTextPlain`, `dataLang`, `CARD_IDS`, `CHINA_CARD`.

Usage: call `await initLanguage()` before the first React render (main.tsx, not mine). In components use
`useI18n()`; keep deferred text as `Message` and render at display time.
