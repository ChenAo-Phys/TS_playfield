## Public API (TypeScript)

```ts
import { DUR, EASE, Z, TIMING, SPEED_FACTOR, frameSpeed, dur, type SpeedSetting, type FrameSpeed,
         layoutFor, trayHeight, fitScale, mapDetail, DESKTOP, TABLET, COMPACT, WIDE_FROM, type LayoutKind, type MapDetail,
         contrastRatio, luminance, over, parseHex } from "./ui/theme";
// once, in the app root:
import "./ui/theme/fonts.css"; import "./ui/theme/tokens.css"; import "./ui/theme/base.css";
```

The `SpeedSetting` values (`slow | normal | fast | instant`) match the existing `ui:settings.speed.*` keys.

## How to run / test

* `npx vitest run tests/theme` → 49 passing. `npx tsc --noEmit -p .` passes.
* Screenshots: `source scripts/pw-env.sh && node docs/design/mockup-final-assets/shoot.mjs [desktop-en …]`. It serves the repo on an
  ephemeral port, maps `/fonts/` → `public/fonts/` and stops afterwards. Scenes: `mockup-final.html?scene=influence|playmode|coup|ai|start&lang=en|zh&view=desktop|compact`.
* `node docs/design/mockup-final-assets/build-names.mjs` regenerates `names.js` from `src/data`.
* I checked that Vite rewrites `url("/fonts/…")` to `/TS_playfield/fonts/…` both in `vite build` and in the dev server (font
  served with 200).

## Decisions the next agents need

* Base = Situation Room identity and desktop. The compact layout is Mobile Clarity's. "If scored now" plates, reveal-dock avoidance,
  the speed control and the anchor/beat model come from Modern Board.
* **Undo = "Undo play"** (back to the start of the current play, only while a human prompt is open). Because of that, the action
  that ends the human's play is staged by default (setting `confirmFinal`).
* The runner commits `frame.state` only after the frame's beats. Components draw `useShown().state`, never `vm.frame.state`.
* `src/ui/ui-contract.ts` is specified verbatim in `ui-spec.md` §15.1. It was typechecked against the current
  `src/game/contract.ts` (`tsc` exit 0 with it in place; the temporary copy was removed). **Someone must create it before the parallel UI work
  starts** (I don't own `src/ui/` outside `theme/`).
